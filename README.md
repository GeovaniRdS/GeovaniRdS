## Projeto em destaque

**[Auto-Triagem de falhas em CI/CD](https://github.com/GeovaniRdS/auto-triagem)** · TCC aprovado

Sabotei de propósito um pipeline real (GitHub Actions self-hosted → Docker → Kubernetes/k3s) para gerar 210 logs de falha em 7 classes, de erro de build a `CrashLoopBackOff`, e comparei 5 classificadores. Uma heurística em regex chegou a 97,6% de acurácia a 0,04 s por log; o melhor LLM, a 86,3% e 3,7 s.
